# Генератор OpenAPI

Отдельный модуль фиксирует oapi-codegen v2.5.0 и совместимые с ним зависимости.
В основном модуле валидатор использует более новую kin-openapi; совмещение зависимостей
раньше ломало сборку генератора из-за изменения MappingRef.

Из корня репозитория:

```sh
make generate
make check-generate
```

`check-generate` генерирует код во временный файл и сравнивает его с `internal/api/api.gen.go`.
Проверка не меняет рабочие файлы и не зависит от того, закоммичены ли текущие изменения.

Версию инструмента можно проверить так:

```sh
go -C tools/oapi-codegen tool oapi-codegen --version
```
